## 背景

機密管理方案的適配性高度取決於**誰要用它**。SOPS+age 是一個 CLI 優先、以 git 為載體、
假設使用者看得懂 `path_regex` 與公鑰模型的方案——這個假設對工程師成立，對非工程師不成立。

拍板當下的現況是**單人（工程師）**，故本刀施工不受影響。但 user 對「團隊組成」的回答不是
「永遠單人」，而是**「將來可能有非工程師」**。這個回答會改變方案的長期形狀，必須當成一個
前提被記下來——否則它會在真的來人的那一天，變成一次沒有紀錄可依循的重新選型。

## 決策

### 1. 團隊組成前提＝「將來可能有非工程師」，據此登記「必須分兩層」為**待觸發架構決定**

- **待觸發**的意思是：**現在不做、也不預留程式碼**（無投機性抽象），但**現在就記下觸發條件
  與屆時的形狀約束**，使觸發時不必從零重新論證。
- **兩層的形狀**（屆時的起手約束，非現在的實作）：
  - **工程師層**＝現況不變——SOPS+age、密文入版控、CLI 程序（RUNBOOK §15）。
  - **非工程師層**＝GUI 取用面（屬「問題 B」射程，見決策 2）；非工程師**不持有 age
    identity**、不跑 `sops`，其取得與交付機密的路徑必須另設。
  - **兩層之間必然需要一個橋接角色**（把值從非工程師層搬進加密檔的人）——這個橋接是新的
    信任集中點，觸發時必須連同它一起設計，不可只挑工具。
- **觸發即重啟選型**：一旦真的出現非工程師成員，「SOPS+age 是否仍是主方案」本身要重評
  （ADR 0079 決策 2 的誠實收窄已載明選型論證只有一條腿）——**不是在現有方案上補一個 GUI**。

### 2. 問題 B（個人密碼管理器選型）＝**維持延後**，登記四個反轉條件

「問題 B」＝是否引入個人密碼管理器（1Password／Bitwarden 等）作為機密的人面載體。
**現在不選、不裝、不評估**；下列任一條件成立即反轉為「必須決」：

| # | 反轉條件 | 現況（2026-07-30） |
|---|---|---|
| ① | **實測閘 #3 失敗且方式 A 的殘餘風險不可接受**（私鑰只能明文落地，需要另一個地方保管根信物） | **未觸發**——#3 全過、B′ 定案（ADR 0080）；退路方式 A 未動用。若日後動用退路，須依 ADR 0080 之退路條款同刀重評本條 |
| ② | **出現非工程師成員** | 未觸發（現況單人工程師）；觸發時與決策 1 的兩層架構同案處理 |
| ③ | **prod 上線且人數 >1** | 未觸發（prod 機密分層本刀不做、遞延 B-115；ADR 0081 決策 2） |
| ④ | **決定以 SSH 金鑰充當 SOPS identity** | **已被本刀禁令結構性封死**——ADR 0080 的 SSH identity 禁令使此條不可能自然成立；要成立必先翻案該禁令（新 ADR） |

**維持延後的理由**：現況單人工程師 × B′（根信物在腦中）× 離線備份義務（ADR 0080）已構成
可運作的閉環；引入密碼管理器會新增一個要維護、要付費、要備份、要信任的元件，而它現在
不解決任何已成立的問題。**這是「暫不需要」，不是「不需要」**——故條件寫死在此，而不是
留在某次對話裡。

### 3. 本刀範圍外的個人側動作**不入 repo 文件**

user 個人側的兩項提醒（無 passphrase 的 ssh 私鑰加固、家目錄某支疑似自動供 passphrase 的
`.sh` 檔用途檢視）屬 **repo 外提醒**——已在 brainstorm 階段口頭交付，**不入 repo 任何文件**，
本 ADR 亦不複述其內容。理由：那是個人主機的狀態，寫進 repo 只會產生一份無人維護、且指涉
per-machine 路徑的過時清單（違反「repo 文件不引用 per-machine 路徑」）。

## 後果

- **本刀施工零影響**：決策 1、2 皆為待觸發項，019 的任何 task 都不依賴它們。
- **觸發時有起點**：非工程師成員到來或 prod 多人化時，不必從零重論——兩層形狀約束（決策 1）
  與四條件（決策 2）即是那次討論的輸入。
- **條件④是被本刀主動封死的**（ADR 0080 SSH 禁令）：這是有意的——把一條「會讓爆炸半徑
  綁上 SSH 私鑰」的路徑，從「可能觸發重評」降級為「必須先翻案才談得上」。
- **殘留的不對稱**：條件②③是**外生事件**（人來了、prod 上了），無法由 repo 內任何機器閘
  偵測；它們的生效依賴人記得回頭讀這份 ADR。這是誠實登記的弱點——治理面的補償是把它們
  同時掛在 BACKLOG B-115（prod 分層包）的觸發語意上，使 prod 刀起手時必然重讀。
